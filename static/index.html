Как проходит тест

Меняется только главное фото. Снимки после него сохраняют порядок. Текущее фото — контроль; после него сервис проверит пять вариантов.

Сервис регулярно проверяет показы и переключает фото после подтверждения порога в статистике WB. После пятого варианта тест завершится и исходное главное фото восстановится. Затем можно сравнить CTR и выбрать фото для карточки.

Для точного CTR нужна CPM кампанияСтатистика WB сгруппирована по дням, поэтому задержка её обновления может повлиять на момент переключения и точность сравнения вариантов.

Про генерацию

Nano Banana Pro через Kie.ai стоит около $0,09 за фото 1K/2K. Пять вариантов — около $0,45 (90 кредитов) по текущей цене. Сначала можно проверить баланс; генерация начинается только после нажатия кнопки и подтверждения.

Фото товара и выбранные фото конкурентов передаются Kie.ai для обработки. Сервис использует конкурентов как общие визуальные ориентиры и сохраняет готовые варианты локально.
