# CTR Lab — Wildberries

Локальное приложение для последовательного сравнения главных фото карточки Wildberries. По введённому nmID оно загружает товар, ищет активные рекламные кампании с этим товаром, создаёт пять вариантов фото через Nano Banana Pro на Kie.ai и измеряет показы, клики и CTR выбранной кампании.

## Подключение ключей

1. Запустите приложение командой ниже и откройте `http://127.0.0.1:8787`.
2. В блоке «Подключение API» укажите:
   - **Wildberries · Контент** — WB API токен с доступом к категории «Контент»: приложению нужно читать карточку и менять фотографии.
   - **Wildberries · Продвижение** — WB API токен с доступом к «Продвижению»: приложению нужно найти активную кампанию и получать её статистику. Если один WB токен включает обе категории, его можно указать в обоих полях.
3. Kie.ai API key задаётся только в локальной конфигурации сервера и не показывается в интерфейсе. В этой установке он хранится в `data/credentials.json` с ограниченными правами доступа; для новой установки задайте переменную окружения `KIE_API_KEY`.

Создавайте WB токены в кабинете продавца в настройках API и выдавайте им только нужные категории. Kie.ai ключ можно создать на [kie.ai/api-key](https://kie.ai/api-key). Не публикуйте ключи и не добавляйте реальные значения в `.env.example`.

## Запуск

Нужен Python 3.10 или новее. Сторонние пакеты не нужны.

```sh
python3 app.py
```

Затем откройте [http://127.0.0.1:8787](http://127.0.0.1:8787). По умолчанию приложение слушает только локальный компьютер.

### Запуск из GitHub

1. Скачайте ZIP-архив репозитория или клонируйте его и распакуйте в отдельную папку.
2. Установите Python 3.10 или новее и запустите `python3 app.py` из папки проекта.
3. Откройте `http://127.0.0.1:8787`, затем подключите свои токены Wildberries «Контент» и «Продвижение» в интерфейсе.
4. Для генерации задайте переменную окружения `KIE_API_KEY` до запуска приложения. Можно использовать собственный ключ Kie.ai или общий ключ владельца проекта. Общий ключ должен передаваться отдельно, безопасным способом: не добавляйте его в GitHub, сообщения коммитов или `.env.example`. Генерации будут списываться с баланса аккаунта, которому принадлежит ключ.

Приложение работает на компьютере, где запущен Python-процесс. Скачивание исходного кода не создаёт публичную ссылку на сайт и не подключает друга к вашим тестам или кабинету Wildberries.

### Запуск на VPS

Для закрытого теста другу разверните отдельную копию приложения с отдельной папкой данных. Так токены Wildberries, фото, тесты и база данных друга будут отделены от вашей локальной установки. Путь задаётся переменной `CTR_LAB_DATA_DIR`, например `/var/lib/ctr-lab-friend`; порт — `CTR_LAB_PORT` (по умолчанию `8787`). На сервере можно задать общий ключ генерации переменной окружения `KIE_API_KEY`; генерации друга будут списываться с баланса этого Kie.ai аккаунта.

Приложение намеренно слушает `127.0.0.1`, поэтому для доступа извне настройте HTTPS reverse proxy с паролем (например, Nginx или Caddy) и проксируйте запросы на локальный порт. Не открывайте порт приложения напрямую в интернет. Не переносите в гостевую установку вашу локальную папку `data/`; запускайте её с чистой отдельной папкой данных.

## Работа с тестом

1. Введите nmID товара и нажмите «Найти товар и рекламу».
2. Приложение загрузит название и главное фото, затем запросит список активных кампаний с этим товаром. Если подходящей рекламы нет, покажет «Активная реклама с этим артикулом не найдена».
3. При желании скачайте и добавьте до четырёх главных фото конкурентов, выбранных вручную. Они служат только визуальными ориентирами для света, фона, контраста и композиции; сервис не копирует чужие товары, бренды и текст. Фото хранятся в localStorage этого браузера и передаются Kie.ai при генерации.
4. Нажмите кнопку генерации и подтвердите стоимость. Nano Banana Pro на Kie.ai стоит около $0,09 за фото 1K/2K (18 кредитов); полный набор из пяти — около $0,45. Проверка баланса не расходует кредиты. Поиск nmID не запускает генерацию автоматически.
5. Выберите активную CPM кампанию и порог 200 либо от 1 000 до 5 000 показов на вариант.
6. Нажмите «Создать тест». Перед запуском приложение сохраняет контрольное фото на этом компьютере. Затем тест проходит по контрольному фото и пяти созданным вариантам; после каждого переключения проверяет, что WB поставил выбранное фото первым.

Статистика WB поступает по дням, поэтому порог проверяется по мере обновления дневной статистики. Когда накопленные показы варианта достигают выбранного значения, устанавливается следующее фото. После последнего варианта приложение загружает сохранённый контрольный файл обратно на первое место карточки. При первом поиске приложение сохраняет текущее фото локально; если прежняя копия отсутствует, нынешнее фото становится новым контролем. Старую ссылку WB восстановить нельзя, если WB уже заменил содержимое по ней.

WB может вернуть клики для кампаний CPC, но не показы и CTR; для порога теста требуется CPM кампания. Во время последовательного сравнения оставляйте цену, ставки, бюджет и настройки рекламы неизменными. Изменение спроса, позиции и конкуренции по времени может повлиять на результат.

Процесс `python3 app.py` должен оставаться запущенным, а компьютер — не переходить в сон. Для круглосуточной работы приложение нужно разместить на постоянно работающем сервере.

## Данные и API

- Тесты и агрегированная статистика: `data/experiments.sqlite3`.
- Сгенерированные варианты: `data/generated/`.
- Локальные копии контрольных фото: `data/originals/`.
- Ключи: `data/credentials.json`.
- Список активных кампаний: `GET /api/advert/v3/adverts`.
- Дневные рекламные показы и клики: `POST /adv/v1/normquery/stats`.
- Генерация редакций фото по исходному изображению: Kie.ai Nano Banana Pro task API; исходное фото передаётся в сервис для обработки.
- Загрузка выбранного фото и изменение порядка медиа карточки выполняются через WB Content API. Исходные и сгенерированные файлы хранятся в локальной папке приложения; держите резервную копию `data/`.

Подробности: [Wildberries Promotion API](https://dev.wildberries.ru/docs/openapi/promotion), [Wildberries Content API](https://dev.wildberries.ru/docs/openapi/item-management), [Kie.ai Nano Banana Pro API](https://docs.kie.ai/market/google/pro-image-to-image), [Kie.ai pricing](https://kie.ai/pricing).
